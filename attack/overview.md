# Overview

This is the Attack phase of the project. In this phase, I utilized the Kali VM to carry out attempts to attack the NAS by finding possible security vulnerabilities. The Attack phase attempts to answer the following questions:

1. Can the Kali VM find the NAS?
2. What does the NAS leave exposed?
3. Can Kali access anything it shouldn't?
4. Can Kali bypass the security controls that have been configured?

Once a security vulnerability is encountered, the attack is halted and immediate remediation is performed to rid the system of said vulnerability.
