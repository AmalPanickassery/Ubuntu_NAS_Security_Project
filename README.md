# Overview
This project involved building a NAS (Network-Attached Storage) server utilizing Ubuntu and Samba in a virtual environment on VirtualBox.
A Kali VM was employed to perform security testing against the NAS's security measures. The identified security weaknesses were documented, remediated, and 
retested to validate that the implemented security changes were effective at reducing the vulnerabilities and as a result minimizing the attack surface.

# Objectives
- Build a functional NAS using Ubuntu Server and Samba
- Apply Linux and network-security hardening
- Put into practice the concept of least privilege
- Perform security testing using a Kali VM
- Identify and remediate the security weaknesses that are encountered during testing
- Validate the security controls by retesting

# Technologies Used
- Ubuntu Server
- Samba
- Kali Linux
- VirtualBox
